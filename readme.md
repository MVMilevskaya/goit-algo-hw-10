## Завдання 1: Порівняння Жадібного алгоритму та Динамічного програмування

### 1. Теоретична складність (О велике)
* **Жадібний алгоритм (`find_coins_greedy`):**
  * **Часова складність:** O(K), де K — кількість номіналів монет. Оскільки кількість номіналів фіксована (6 монет), складність фактично є **O(1)** і не залежить від суми N.
  * **Просторова складність:** O(1).
* **Динамічне програмування (`find_min_coins`):**
  * **Часова складність:** O(N * K), де N — сума решти, K — кількість номіналів монет.
  * **Просторова складність:** O(N) для збереження масиву `dp`.

### 2. Практичні результати та висновки
1. **Канонічна система монет:** Для стандартного набору монет `[50, 25, 10, 5, 2, 1]` жадібний алгоритм **завжди знаходить оптимальне рішення** (мінімальну кількість монет), аналогічно до методів ДП.
2. **Продуктивність при великих сумах:** При збільшенні суми (наприклад, N = 10000) жадібний алгоритм виконується миттєво, тоді як алгоритм ДП потребує виділення значного обсягу пам'яті та значно більше часу на заповнення таблиці dp[N].
3. **Підсумок:** Для стандартних грошових систем жадібний алгоритм є безумовно ефективнішим завдяки лінійній швидкості та відсутності накладних витрат пам'яті.

   **Результат порівняння вказано нижче:**
--- Порівняння продуктивності на великій сумі (10000) ---
Greedy time for 10000: 0.000006 сек
DP time for 10000:     0.009268 сек

## Завдання 2: Обчислення інтеграла методом Монте-Карло

Для обчислення визначеного інтеграла функції f(x) = x^2 на інтервалі [0, 2] було проведено серію симуляцій з N = 500000 випадкових точок.

### Результати обчислень:
* **Аналітичне значення (та `scipy.integrate.quad`):** 2.666667 (8/3)
* **Значення методом Монте-Карло:** ~ 2.665296
* **Абсолютна похибка:** < 0.001371

### Висновки:
Метод Монте-Карло демонструє високу точність надання наближеного значення інтеграла при достатньо великій кількості точок (від 100 000 і більше). Проте аналітичний метод та функція `quad` є значно точнішими та швидшими для одновимірних гладких функцій. Метод Монте-Карло є незамінним підходом для багатовимірних інтегралів або складних геометрій підінтегральних областей
